# ميزان

تطبيق ويب مختصر لميزانية الأسرة في صفحة واحدة، يعمل دون إنترنت بعد أول فتح: ملخص الشهر، الدخل (راتب ودخل إضافي)، المصروفات (ثابتة وطارئة، ومن أين تُدفع)، الديون، والادخار (يدوي وتلقائي من المتبقي)، والإعدادات (النسخة الاحتياطية والرقم السري).

البيانات تُحفظ في جهاز المستخدم فقط (لا خادم ولا حسابات). صدّر نسخة احتياطية من «الإعدادات» واستوردها عند تغيير الجهاز.

للتثبيت: افتح رابط GitHub Pages في Safari ثم «مشاركة» ← «إضافة إلى الشاشة الرئيسية»، أو في Chrome ← «تثبيت التطبيق».

# ميزان

تطبيق ويب لميزانية الأسرة يعمل دون إنترنت بعد أول فتح: الدخل والموارد، المصروفات (التقديرية والفعلية وغير المجدولة)، الديون والالتزامات، الادخار، الاستثمار، الزكاة، والملخص المالي.

البيانات تُحفظ في جهاز المستخدم فقط (لا خادم ولا حسابات). استخدم «النسخة الاحتياطية» داخل التطبيق لتصدير بياناتك واستيرادها.

للتثبيت: افتح رابط GitHub Pages في Safari ثم «مشاركة» ← «إضافة إلى الشاشة الرئيسية»، أو في Chrome ← «تثبيت التطبيق».
